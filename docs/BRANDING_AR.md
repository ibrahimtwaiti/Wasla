# إضافة الهوية البصرية لاحقًا

الواجهة الحالية أساس مؤقت من درجات الأخضر الداكن والحيادي، دون ادعاء اعتماد شعار نهائي.

1. متغيرات الألوان والخط والمسافات ونصف القطر في بداية `wasla/static/styles.css` تحت `:root`.
2. العلامة المؤقتة في `wasla/static/favicon.svg` ومكون `logo()` في `app.js`.
3. يمكن استبدال Tahoma بخط مرخص ذاتي الاستضافة؛ أضف الملفات داخل static وحدّث `@font-face` ومتغير `--font`. لا تعتمد CDN لبيانات الهوية.
4. النصوص الأساسية في catalog.py وapp.js، وبيانات الجهة القابلة للتحرير في إعدادات محتوى الموقع.
5. راجع تباين الألوان وحالات التركيز والعربية بعد التغيير. حافظ على جميع تسميات النماذج ومؤشرات حالات الفشل والنجاح.
6. اختبر عرض 390 و768 و1366 بكسل ومحتوى طويل ومختلط الأرقام واللغة.

توجد بنية فصل بيانات كتالوج وقاموس حالات، لكنها ليست نظام ترجمة مكتملًا. إضافة الإنجليزية تحتاج استخراج بقية النصوص إلى ملفات locale، تبديل lang/dir، تنسيق تاريخ وعملة واختبارات LTR. لا يوجد زر لغة غير عامل.
