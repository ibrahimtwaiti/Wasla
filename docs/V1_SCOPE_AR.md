# نطاق Wasla V1 ومطابقة خريطة البناء

## تفسير الإصدار

الملف المرفق يحدد إطلاقًا كاملًا عبر ست مراحل، ولا يعرّف V1 كنسخة مستقلة شاملة كل تلك المراحل. لهذا عُرّف V1 كتأسيس قابل للتشغيل للمراحل 1–3 وجزء من المرحلة 4. لم يُخفَ النقص تحت وصف «مكتمل». تعريف النطاق قرار تنفيذ لهذه النسخة وليس موافقة من صاحب المشروع على إسقاط بقية المتطلبات.

## بوابة قبول V1

يمكن قبول V1 كقاعدة تطوير وتجربة داخلية عند نجاح طلب → مراجعة → عرض → قبول → مشروع، وشركة → أعضاء → عميل → فرصة → متابعة → إغلاق موثق. لا يجوز اعتباره منصة اتصالات تجارية مكتملة ما دام الرد الخارجي وباقي وحدات الإطلاق الكامل غير منفذة.

الاختبارات الحية لمزود واتساب لا تُستبدل باختبارات أحداث اصطناعية. لا يغيّر نجاح اختبار API حالة القناة إلى متصل.


> تحديث 13 نوفمبر 2026: اعتمد المالك الاستغناء عن MFA، وقبول مخاطر مفاتيح R2 المكشوفة مؤقتًا داخل V1. نُفذت قواعد R2 والجلسات وبعض سياسات الحذف واختُبرت؛ يبقى استيفاء الهوية القانونية والنقل والحذف الكامل شرطًا منفصلًا للاعتماد التجاري النهائي. المرجع: `docs/V1_OWNER_GOVERNANCE_AR.md` و`docs/V1_CLOSEOUT_AR.md`.
