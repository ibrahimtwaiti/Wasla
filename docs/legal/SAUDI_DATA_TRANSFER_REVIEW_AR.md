# سجل تقييم نقل بيانات Wasla V1 خارج المملكة — مسودة مراجعة

القرار التجاري للمالك هو استهداف السوق السعودي. يعالج مشروع V1 بيانات محتملة لأشخاص في السعودية، والمواقع الحالية للموردين تشمل خارج المملكة. **اعتماد استخدام مزود لا يعني اعتماد امتثال نقل البيانات تلقائيًا**.

| المورد | الغرض | الموقع المعروف | التقييم |
|---|---|---|---|
| Neon | قاعدة PostgreSQL الرئيسية | Frankfurt, Germany | يحتاج مراجعة المتطلبات والضمانات وأحكام المعالجة |
| Cloudflare R2 | نسخ احتياطية غير مشفرة بمفتاح مستقل | APAC, default jurisdiction | يحتاج تقييم نقل البيانات وسرية المفاتيح والإقامة الفعلية |
| Vercel | تقديم واجهة/API الموقع | يجب إثبات منطقة التنفيذ والتخزين والسجلات | لم تتحقق إقامة معالجة كل مكون |
| GitHub | الكود وعمليات CI، ومعلومات تشغيل غير حساسة | خدمة عالمية | يُمنع تضمين بيانات العملاء في السجلات وartifacts |

## ما يلزم إثباته
1. حصر فئات البيانات الشخصية في كل خدمة وسبب الحاجة لنقلها خارج المملكة.
2. تحديد دور الجهة المتحكمة والمعالجين الفرعيين، ومراجعة اتفاقيات المعالجة المنشورة.
3. تقييم مسوغات نقل البيانات وضمانات الحماية والأثر على ممارسة حقوق أصحاب البيانات والإتلاف والإبلاغ عن الحوادث، وفق نظام حماية البيانات الشخصية ولوائحه ولوائح النقل.
4. مراجعة أية متطلبات إقامة بيانات خاصة بنوع العملاء أو القطاع (ولا يُدَّعى أنها مستوفاة هنا).
5. توثيق قرار المسؤول القانوني بعد الاطلاع على الأدلة؛ لا يبدأ استقبال بيانات حساسة عامة قبل إغلاق المسوغات.

مراجع رسمية: https://dgp.sdaia.gov.sa/ ، https://sdaia.gov.sa/ .

**الحالة:** قائمة تحقق تشغيلية جاهزة؛ الامتثال القانوني النهائي مشروط بأدلة وأسماء الجهة المسجلة والمراجعة المختصة.
