# تحقق تطبيق الهوية

- اختبارات المشروع بعد البناء فوق فرع Neon/Vercel: 52 اختبارًا؛ 48 ناجحة، 4 PostgreSQL تم تجاوزها محليًا لعدم توفير قاعدة اختبار PostgreSQL مستقلة. لا يُدّعى اختبارها هنا.
- الاختبارات الثمانية الجديدة: قراءة الافتراضيات وCSS، منع غير المسجل ومدير الشركة، حفظ provider واستمراره، حماية CSRF، رفض حقن CSS/روابط غير آمنة، رفض SVG نشط، قبول SVG آمن وإعادة الأصل، رفض صورة غير صالحة أو كبيرة.
- تحقق syntax لـapp.js وbrand.js وcompileall لبايثون.
- فحص مرئي فعلي في المتصفح للصفحة الرئيسية على عرض الكمبيوتر: الشعار، الخط المحلي، Hero والمنصة التوضيحية. فحص DOM يثبت الأقسام وروابط الخدمات وFAQ. لا أخطاء تطبيق في سجل المتصفح المرصود.
- التصميم يتضمن media queries للهاتف واللوحي وreduced-motion، لكن لا يُدّعى إجراء محاكاة فعلية لكل أحجام الأجهزة أو اختبار Safari/Firefox في هذه البيئة.
- محرر الهوية اختُبر عبر API؛ لم يُنشأ حساب مدير إنتاجي أو كلمة مرور افتراضية لأجل الاختبار.
- الواجهة لا تغيّر حقيقة نطاق المنصة: الإرسال الخارجي لواتساب والتكاملات المذكورة كغير مفعلة تبقى كذلك.
- معاينة Vercel منفصلة عن Production؛ تهيئة المدير واشتراطات تشغيل الإنتاج تبقى كما في دليل النشر السابق.
