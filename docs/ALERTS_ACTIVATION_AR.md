# تفعيل تنبيهات Wasla التشغيلية — نوفمبر 2026

## المسؤول والوجهة
المسؤول التشغيلي الوحيد والمستلم هو مالك مستودع `ibrahimtwaiti/Wasla`.
اعتمد المالك بريدًا شخصيًا بديلًا في إعدادات GitHub. **لا تُنشر عناوينه الشخصية في هذا المستودع العام**.

يجب التأكد في إعدادات حساب GitHub (Settings → Emails وSettings → Notifications) من اختيار البريد المعتمد والتحقق منه وتفعيل إشعارات مشاركات الحساب وGitHub Actions عبر Email. لا تمتلك مهمة GitHub Actions القدرة على تعديل إعدادات الحساب الشخصية.

## طريقة التنبيه
تراقب `.github/workflows/ops-alerts.yml` فشل:
- `Production health`،
- `Production queue health`،
- `PostgreSQL database backup to R2` (بعد دمج مهمة النسخ في `main`).

عند فشل إحدى المهام في `main`، تنشئ GitHub Issue مسندة إلى `ibrahimtwaiti`. لا تنشئ نسخًا متكررة من التنبيه المفتوح نفسه. يفحص تشغيل مجدول كل 6 ساعات عمر آخر نسخة احتياطية ناجحة، ويفتح تنبيهًا إن لم تتوفر نسخة ناجحة خلال 26 ساعة؛ يتجنب الفحص الإبلاغ عن أي نسخة احتياطية قبل نشر workflow النسخ في `main`.

لا توجد بيانات قاعدة أو أسرار ضمن Issues. Issue مسندة إلى المالك تعني أن التنبيه أنشئ داخل GitHub **ولا تعني أن رسالة البريد قد وصلت**.

## تجربة الإشعار
عند الدمج الأولي إلى `main`، تُصدر مهمة التنبيه Issue اختبارية آمنة بعنوان `[Wasla TEST]`، مسندة إلى المالك. هذه ليست حالة فشل في الموقع أو قاعدة Neon.

1. افتح صفحة Actions وتأكد من نجاح تشغيل `Wasla operational alerts`.
2. افتح Issue التجريبية، وتحقق أنها مسندة إلى `ibrahimtwaiti` ولا تحتوي على أسرار.
3. تحقق من وصول إشعار `notifications@github.com` أو رسالة GitHub المقابلة إلى البريد الشخصي المعتمد، وافحص Spam.
4. سجّل نتيجة الاستلام الفعلية وتوقيتها، ثم أغلق Issue التجريبية.
5. إذا لم تصل الرسالة، تحقق من إعدادات GitHub Notifications وWatching لهذا المستودع، ثم أعد اختبار `workflow_dispatch` مرة أخرى.

**بوابة الاعتماد:** لا تُسجَّل حالة `Email Delivered` إلا بدليل رسالة بريد مستلمة. لا يُعد نجاح تشغيل Actions وحده إقرارًا بالوصول.

## حدود التفعيل
هذا المسار لا يرسل رسائل SMTP مباشرة ولا يغيّر Vercel أو Neon أو R2 أو سياسة الاحتفاظ أو اعتماد V1 النهائي. يمكن للمالك تعديل بريد الإشعارات عبر حساب GitHub دون تعديل الشفرة.
