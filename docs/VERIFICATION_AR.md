## التحقق من الواجهة في المتصفح

- عرض الصفحة الرئيسية على سطح المكتب وفحص التخطيط العربي واتجاه RTL.
- فتح كتالوج الخدمات والتصفية إلى «المنصة والتقنية»، فظهرت خدمات المنصة وCRM وربط واتساب.
- فتح تفاصيل CRM والانتقال إلى النموذج؛ الخدمة محددة مسبقًا بصورة صحيحة.
- تعبئة بيانات اصطناعية فقط وإرسال الطلب، ثم ظهور «تم حفظ طلبك بنجاح» ورقم مرجعي.
- لا إرسال خارجي أو بريد أو بيانات عميل حقيقية أثناء الاختبار.

لم تُجرَ مراجعة مرئية كاملة لكل شاشات اللوحة بعد الدخول، ولا محاكاة جوال أو قارئ شاشة أو قياس Lighthouse؛ استُخدمت اختبارات API للتحقق من المصادقة واللوحات الخلفية. CSS يتضمن نقاط استجابة 760 و1050 بكسل، لكن وجودها وحده ليس إثبات اختبار جوال.
