# Wasla V2 تنفيذ دليل المحادثات وخدمة العملاء

مرجع التنفيذ: social_api_customer_service_guide_ar.docx، إصدار 13 نوفمبر 2026. تاريخ العمل: 14 نوفمبر 2026. الفرع: feat/v2-social-service.

## حالة الإصدار

مرشح تطوير، وليس اعتمادًا بأن جميع حسابات التواصل متصلة أو أن اختبارات الإنتاج الحية اكتملت. V1 محفوظ، وواجهاته وسجلاته السابقة متاحة من زر «سجل V1». لا تُرحّل المحادثات القديمة تلقائيًا إلى هويات القنوات الجديدة دون مراجعة ملكية الحسابات.

## مصفوفة الدليل

| الفصل | التنفيذ | بوابة الإطلاق أو الحد الباقي |
|---|---|---|
| 1 النطاق | قدرات مستقلة للقنوات، تيك توك awaiting_approval وسناب referral_only | لا تمثل الإعلانات أو النشر دعمًا للمحادثات |
| 2 الاعتمادات | مرجع سر مستقل لكل حساب، تفويض إنستغرام مرتبط بالجلسة والمستخدم والمنشأة، تشفير الرمز، فحص أصل الحساب وفصل وإعادة تفويض | يتطلب تطبيقًا معتمدًا وموافقة المالك؛ MFA داخل Wasla لا يُفرض بناءً على قرار المالك السابق، ومتطلبات المنصات مستقلة |
| 3 واتساب | استقبال موقع وحفظ دائم، إزالة تكرار، إرسال نص وقالب ثابت وصورة أو PDF، حالات مستقلة، قوالب تُزامن من الأصل المثبت | حساب Meta ورقم مخول وقوالب وموافقة فعلية واختبار هاتف؛ القوالب ذات المعاملات أو المكونات غير المدعومة تُرفض بوضوح |
| 4 إنستغرام | Instagram Login، OAuth وتجديد الرمز، استقبال نص وأنواع غير مدعومة بوصف واضح، منع حلقات echo، رد نصي خلال 24 ساعة | App Review واختبار حساب خارج أدوار التطبيق؛ HUMAN_AGENT والتعليقات غير مفعلة |
| 5 تيك توك | سجل حساب وحالة أهلية واضحة ومنع إرسال غير مخوّل | Business Messaging Approval وعقد Webhook الخاص بالحساب؛ لم يُختلق موصل من مخطط Meta |
| 6 سناب | تمييزه كمصدر إحالة وعدم ادعاء مزامنة DM | ربط Public Profile/الإحصاءات أو Creator Collaboration يحتاج السماح الرسمي والأصل؛ غير منفذ كموصل حي |
| 7 البنية | جداول منفصلة، Inbox وOutbox، عامل، SSE للتحديث، عزل المنشآت، تشفير رموز OAuth | ربط الجدولة بمرشح المعاينة وإعداد مخزن وسائط خاص وفاحص ملفات |
| 8 مشغل المحادثات | Wasla هو الصندوق والمشغل، ورد الموظف يمر عبر السياسة والطابور | لا تكامل وهمي مع مورد ثالث غير محدد؛ ربط مورد خارجي يتطلب اختيار المنتج وعقوده |
| 9 البيانات | Account/Identity/Ticket/Message/Consent/Event/Outbox/Status history، ربط هويات موثق وقابل للإلغاء | الروابط لا تدمج الأشخاص بالاسم أو الصورة، ولا تعيد كتابة مصادر التذاكر |
| 10 الموثوقية | توقيع الجسم الخام، رفض الأصل المجهول، حفظ قبل 200، إعادة محاولة 429 وConnectError، DLQ، تسوية نتيجة مجهولة، تدقيق تنزيل وتصدير | التايم آوت و5xx بعد الإرسال لا يعادان تلقائيًا؛ الفحص الحي وإدارة التنبيهات مطلوبان |
| 11 الخدمة | حالات كاملة، تصنيف أولي، إسناد وسعة، تعارض الإصدار، ساعات وإجازات الرياض، ردود محفوظة، تصعيد وسبب حل، موافقات، تقييم موثق | لا إرسال آلي بالذكاء الاصطناعي ولا إجراء حجز غير موثق |
| 12 التقارير | أول رد بشري وP90 ووقت الدوام وSLA والمتراكم والتسليم وCSAT، فلاتر API وفترات التغطية | الحجز الفعلي غير مربوط؛ يظهر null. CSAT يُسجل مع مصدره يدويًا ولا يرسل استبيانًا تلقائيًا |
| 13 القبول | اختبارات توقيع وتكرار وتعطل وعزل وتزامن وسياسة ورسائل وواجهة | نتائج الاختبار الحي والأداء بالحجم الفعلي والاستعادة الجديدة لا تُستبدل بنتائج mocks |
| 14 التسليم | الكود والترحيل وعقود المسارات والإعدادات وخطة التراجع وهذا السجل | الاعتماد الكامل يتطلب إغلاق البوابات الخارجية والحدود المعلنة |

## القيود البرمجية المعلنة

- مرفقات الوارد من القنوات تظهر كنوع غير مدعوم؛ جلب ملفات المزود وفحصها تلقائيًا غير مكتمل. رفع الموظف وفحصه وتخزينه الخاص وروابطه المؤقتة منفذ.
- قوالب واتساب المدعومة حاليًا ثابتة دون معاملات أو Header/Buttons. مزامنة أول 100 قالب تُعلّم partial عند وجود صفحة تالية؛ القوالب غير المتزامنة لا تصبح معتمدة تلقائيًا.
- لا موصل TikTok حي، ولا Snap Public Profile أو تعاون Creator؛ هذه بوابات منتج ووصول تتطلب بيانات الحساب ووثائقه.
- لا موصل حجز فعلي أو CRM خارجي، ولا مساعد توليدي أو حملات أو سرد كامل لأرشيف المنصات.
- تقارير الواجهة تعرض 30 يومًا؛ API يقبل الفترة والقناة والفريق والفرع والموظف والتصنيف والأولوية. المتراكم حالة حالية لمجموعة الطلبات المنشأة في الفترة وليس لقطة تاريخية.
- لا حذف آلي جديد لمحتوى المحادثات دون تثبيت سياسة الاحتفاظ والتزامات العملاء. حذف V1 المحافظ ونسخه الاحتياطي يبقيان كما هما. يجب تغطية ملفات R2 وسجل الحذف عند اعتماد دورة حياة V2.

## مسارات API

كل مسارات /api/v2 تتطلب جلسة Wasla؛ التغييرات تتطلب Origin وCSRF. Webhooks فقط تستخدم توقيع المزود. أسماء حقول النسخة تفصل عن V1.

| المسار | الوظيفة |
|---|---|
| GET/POST /api/v2/accounts | سجل القنوات وقدراتها |
| POST /api/v2/accounts/{id}/check | فحص وصول الرمز إلى الأصل |
| POST /api/v2/accounts/{id}/disconnect | تعطيل الحساب ومسح رمز OAuth وحالات التفويض |
| POST /api/v2/accounts/{id}/oauth/start | رابط Instagram Login مع state أحادي الاستخدام |
| GET /api/v2/oauth/instagram/callback | صفحة عودة تستأنف العملية من نفس الموقع دون إضعاف SameSite=Strict |
| POST /api/v2/oauth/instagram/complete | تبادل code والتحقق من الأصل والصلاحيات وتخزين الرمز المشفر |
| POST /api/v2/accounts/{id}/oauth/refresh | تجديد رمز إنستغرام المؤهل |
| GET/POST /api/webhooks/v2/{channel} | التحقق ثم استقبال أحداث واتساب وإنستغرام |
| GET /api/v2/tickets | قائمة مع البحث والحالة والقناة |
| GET/PATCH /api/v2/tickets/{id} | التفاصيل والإسناد والتصعيد والحالة مع version |
| POST /api/v2/tickets/{id}/messages | note أو out، يتطلب Idempotency-Key وversion |
| GET /api/v2/tickets/{id}/stream | SSE محدود المدة وقابل لإعادة الاتصال |
| POST /api/v2/tickets/{id}/attachments | base64 مع MIME؛ PNG/JPEG/PDF، بحد 5 MB وفحص إلزامي |
| GET /api/v2/attachments/{id}/download | رابط خاص لمدة 120 ثانية بعد التحقق من الصلاحية |
| POST /api/v2/identities/{id}/consents | تسجيل موافقة محددة أو سحبها مع الدليل |
| POST/DELETE /api/v2/identity-links[/id] | ربط موثق وإلغاء قابل للتدقيق |
| GET/PUT /api/v2/settings | ساعات العمل والإجازات والسعة والمتاحون وإيقاف الإرسال |
| GET/POST /api/v2/replies | الردود المحفوظة |
| GET /api/v2/templates | القوالب المتزامنة |
| POST /api/v2/accounts/{id}/templates/sync | إثبات علاقة WABA بالرقم وجلب القوالب |
| GET /api/v2/operations | حالة Inbox/Outbox والرسائل التي تحتاج مراجعة |
| POST /api/v2/events/{id}/retry | إعادة حدث وارد مستنفد مع تدقيق |
| POST /api/v2/outbox/{id}/reconcile | تسوية موثقة دون إعادة إرسال عمياء |
| POST /api/v2/tickets/{id}/rating | تسجيل تقييم 1–5 مع مصدر |
| GET /api/v2/reports | تقارير الفترة والفلاتر |
| GET /api/v2/export | CSV محدود لصاحب صلاحية التصدير ومسجل بالتدقيق |

## إعداد التشغيل

1. جهّز قاعدة PostgreSQL معزولة للمعاينة. نفذ `python -m wasla.cli init` باستخدام الاتصال المباشر. الترحيل 004 إضافي ولا يحذف جداول V1.
2. سجّل الحساب في شاشة القنوات. يخرج معرّف المتغير `WASLA_CHANNEL_<ACCOUNT_ID_UPPERCASE>_TOKEN`؛ احفظ القيمة في أسرار البيئة فقط. لا تقبل الواجهة اسم متغير حر يمكن أن يشير إلى سر لشركة أخرى.
3. اضبط META_APP_SECRET وMETA_VERIFY_TOKEN لواتساب. إنستغرام يستخدم INSTAGRAM_APP_SECRET وINSTAGRAM_APP_ID. ثبت api_version الذي اختبره الحساب.
4. لتفويض إنستغرام اضبط WASLA_TOKEN_ENCRYPTION_KEY بمفتاح Fernet عشوائي، وWASLA_ORIGIN بنطاق HTTPS المطابق للعنوان المسجل. احتفظ بالمفتاح خارج قاعدة البيانات وبنسخة محمية لاستعادة الرموز المشفرة.
5. اضبط اشتراك التطبيق والحساب وحقول الرسائل لدى المنصة. نجاح GET challenge لا يثبت الاشتراك ولا App Review.
6. الجدولة الحالية `/api/internal/drain-webhooks` تستدعي أيضًا عامل V2 مع WASLA_WORKER_SECRET. العامل يحفظ إرسال queued أولًا، ثم sending، ثم accepted أو حالة فشل محددة. التوقف بعد sending يتحول إلى unknown بعد مهلة ولا يعاد إرساله تلقائيًا.
7. الوسائط تحتاج حاوية R2 خاصة منفصلة عن النسخ الاحتياطية: WASLA_MEDIA_ENDPOINT وWASLA_MEDIA_BUCKET وWASLA_MEDIA_ACCESS_KEY_ID وWASLA_MEDIA_SECRET_ACCESS_KEY. لا تستخدم مفاتيح أرشيف النسخ لهذا الغرض.
8. الفاحص: WASLA_MEDIA_SCANNER_URL بعنوان HTTPS وWASLA_MEDIA_SCANNER_TOKEN. عقده POST بايتات الملف مع MIME وX-Content-SHA256؛ يرجع JSON `{ "verdict": "clean", "sha256": "..." }`. الفشل أو اختلاف البصمة يمنع التخزين والإتاحة. يجب أن يكون الفاحص معتمدًا لاستقبال بيانات العميل.
9. حدد الموظفين المتاحين والسعة والدوام والإجازات في Asia/Riyadh. صفر موظفين متاحين يعني بقاء الطلب غير مسند.
10. نفذ اختبار هاتف حقيقي وارد ورد وملف وحالة تسليم وتفويض مسحوب لكل حساب قبل اعتماد الربط.

## الرجوع والتشغيل

- فعّل sending_paused لإيقاف الإرسال مع استمرار حفظ الوارد. لا تحذف الطوابير.
- راجع unknown لدى المزود ثم سجل دليل التسوية ومعرف الرسالة أو ألغها. لا تعرض إعادة إرسال تلقائية.
- يمكن الرجوع إلى نشر V1 مع إبقاء جداول V2؛ عطل استقبال V2 في لوحة المزود أو استمر بخادم V2 لاستقباله بصورة آمنة. لا تسقط الجداول المحتوية بيانات.
- النسخ الحالية PostgreSQL تشمل الجداول الجديدة تلقائيًا. يجب اختبار استعادة V2 إلى قاعدة منفصلة، مع استعادة مفتاح التشفير بصورة مستقلة، قبل Production. الاختبار السابق لـ V1 لا يثبت استعادة V2.
- تنزيل الملف برابط مؤقت يمنح وصولًا لمدة 120 ثانية لحامله. تتطلب سياسة حذف الملفات والنسخ الاحتياطية اعتمادًا مستقلًا، ولا يُزعم إكمالها بهذه النسخة.
