# وصلة — تحليل المرجع ونظام التصميم

تاريخ الفحص: 12 نوفمبر 2026. المرجع: https://chatcentersa.com/ . التنفيذ مستقل، ولا يتضمن ملفات المرجع أو شعاره أو خطه أو إحصاءاته أو ادعاء الشراكة مع Meta.

## 1. ما تم التحقق منه في المرجع

فحص مباشر للصفحة الرئيسية، تبديل الإنجليزية والعربية، التنقل إلى الخدمات، لقطة للواجهة والبطاقات، قراءة CSS العام وقياسات computed style للعناصر الظاهرة. هذه ملاحظات للصفحة الرئيسية في الجلسة الحالية، وليست تدقيقًا لكل الصفحات الداخلية أو لكل حالات الهاتف.

| العنصر | الملاحظة المثبتة | قرار وصلة |
|---|---|---|
| الهيدر | شريط أعلى الصفحة، روابط أقسام، قائمة أسعار، لغة، مظهر، CTA | شريط فاتح ثابت، تنقل مختصر، دخول وبدء، قائمة هاتف قابلة للإغلاق |
| Hero | عنوان مركزي على سطرين، خلفية داكنة وشبكة وإضاءة خضراء، زران | تكوين ثنائي: رسالة عربية ومنصة توضيحية؛ بنفسجي داكن مع أصفر |
| الخدمات | 10 بطاقات، شبكة خمسية في لقطة الكمبيوتر، أيقونات خطية | 6 خدمات رئيسية بشبكة ثلاثية ورابط لجميع خدمات Wasla الإحدى عشرة |
| البطاقات | حدود رفيعة، زوايا ناعمة، إضاءة عند المؤشر، ظهور رابط التفاصيل | بطاقات بيضاء، ظل ناعم، ارتفاع 6px وحد بنفسجي؛ الرابط ظاهر دائمًا |
| من نحن | نص مع فوائد وأرقام وCTA | قصة العلامة ورسم اتصالات وفوائد تشغيلية بلا أرقام أداء غير مثبتة |
| التواصل | معلومات اتصال ونموذج أربعة حقول ورابط واتساب | CTA يصل إلى نموذج الطلب الفعلي الموجود، بيانات التواصل المعتمدة من الإدارة |
| التذييل | شعار وروابط وسياسات | شعار ومجموعات روابط وتواصل قابل للتحرير |
| الخط | Hanimation Arabic بأوزان 300–700؛ Space Grotesk في بعض العناصر | Tajawal عربي وManrope لاتيني، ذاتيا الاستضافة مع رخص OFL |
| القياسات | H1: 72px؛ H2: 48px في جلسة الكمبيوتر؛ CTA:18px وradius:12px | H1 مرن 38–58px؛ H2 مرن 30–44px؛ أزرار 15px |
| الحركة | انتقال CTA بقيمة 300ms cubic-bezier(.4,0,.2,1)؛ ارتفاع وتكبير وإضاءة في CSS، floating/pulse-glow/shine | انتقال 240–300ms، ظهور 600ms، طفو خفيف 6s؛ بدون وميض أو تحريك مستمر للنص |

ملاحظة الدقة: وجود keyframes في CSS المرجع لا يعني أن كل حركة مفعلة على كل عنصر. تأكد بصريًا تغير البطاقات عند المؤشر والتنقل بين الأقسام، وتبديل اللغة واتجاه الصفحة. لم تُستنتج أزمنة حركات JavaScript من الشكل وحده. أرقام العملاء والمبيعات في المرجع لم تُنسخ.

## 2. هوية Wasla

قيم الألوان من لوحة الهوية المرفقة:

| Token | القيمة الافتراضية | الاستخدام |
|---|---|---|
| `--brand` | `#834DFB` | روابط، أيقونات، لون رئيسي |
| `--accent` | `#F0E100` | CTA على الخلفية الداكنة وتأكيدات بصرية |
| `--ink` | `#1B102B` | النص والخلفيات الداكنة |
| `--paper` | `#F5F3FF` | خلفية الصفحة |
| `--surface` | `#FFFFFF` | بطاقات ونماذج وشريط تنقل |
| `--muted` | `#70677E` | نص ثانوي على الخلفية الفاتحة |
| `--line` | `#E7E1F0` | فواصل وحدود |
| `--radius` | `24px` | بطاقات وأقسام، قابل للتعديل 0–40 |
| `--shadow` | `0 16px 48px #1b102b0b` | ظل ناعم قابل للإلغاء |
| `--logo-width` | `166px` | قابل للتعديل 100–230 |
| `--logo-padding` | `4px` | قابل للتعديل 0–20 |
| `--space-section` | `100px / 64px` | فراغ عمودي كمبيوتر / هاتف |
| `--duration` | `240ms` | تفاعل قصير |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | خروج هادئ |

تباين البنفسجي الأساسي على الأبيض يقارب 4.75:1. تُستخدم درجة أغمق مشتقة للنصوص الصغيرة على الخلفية اللافندر؛ يستخدم اللون الداكن للنص الأساسي، ويجب إعادة مراجعة التباين عند تخصيص الألوان. لا توجد ضمانة تباين لألوان يختارها المدير عشوائيًا.

### سلم الطباعة والمسافات

- H1: `clamp(38px,4.1vw,58px)`، ارتفاع 1.35؛ هاتف `clamp(34px,8.5vw,52px)`.
- H2: `clamp(30px,3.5vw,44px)`، ارتفاع 1.35.
- H3: 18–21px؛ النص 15–17px بارتفاع 1.8–2؛ تسميات 12–14px.
- أحجام 8–10px داخل الرسم التوضيحي فقط، وليست حقول تحكم فعلية.
- المسافات: 8، 12، 16، 20، 24، 32، 40، 64، 100px حسب التسلسل.
- الحاوية 1220px كحد أقصى؛ جوانب 32px على الكمبيوتر و16px على الهاتف.
- نقاط التحول 760px و1100px. شبكة الحلول 3 أعمدة ثم عمود؛ المنصة عمودان ثم عمود؛ قائمة الهاتف تستخدم زرًا مع `aria-expanded`.

## 3. المكونات والحركة

- `brandLogo`: الشعار عبر جميع الأغلفة العامة ومساحة العمل. الصورة الأصلية المرفقة محفوظة كما هي، ويُضبط عرضها بـCSS؛ الشعارات المرفوعة تستخدم contain دون قص.
- `icon`: SVG خطي أصلي، حجم 24px وخط 1.7px؛ اتجاه السهم قابل للعكس في LTR.
- `publicShell`: الهيدر والتذييل المشترك، معلومات التواصل وروابط العلامة.
- `sectionTitle` و`serviceTile`: تسلسل عنوان وبطاقة خدمة قابلة لإعادة الاستخدام.
- `productVisual`: رسم واجهة بالـHTML/CSS، معلّم كبيانات افتراضية؛ لا يوحي بإرسال واتساب فعلي.
- الظهور: IntersectionObserver مرة واحدة، opacity + translateY(18px)، 600ms؛ المحتوى مرئي افتراضيًا إذا لم يتوفر observer.
- Hover: البطاقات ترتفع 6px؛ الأزرار 2px؛ السهم 4px. التنقل السلس يحترم reduced-motion.
- الطفو: بطاقة اتصال صغيرة تتحرك 7px خلال 6s؛ يُوقف بالكامل مع تفضيل تقليل الحركة.
- FAQ يستخدم `details/summary` الأصلي مع فتح بلوحة المفاتيح؛ القائمة تغلق بـEscape وبعد اختيار رابط.
- CSS يعطل كل animation/transition/scroll-smoothing عند `prefers-reduced-motion:reduce`.

## 4. إدارة الهوية

من حساب **مدير مقدم الخدمة**: مساحة العمل ← محتوى الموقع ← الهوية البصرية.

1. عدّل الاسمين والألوان والخطين والحواف والظلال وأسلوب الأيقونات.
2. ارفع شعار الخلفية الفاتحة أو الداكنة (PNG أو SVG)، حتى 500KB للملف. يُعرض شعار الخلفية الداكنة في Hero عند توفيره.
3. عدّل عرض الشعار ومساحته وموقعه. على الهاتف يعود للبداية لحماية مساحة التنقل.
4. يمكن استبدال رسم Hero بصورة من نفس الصيغ. لإعادة الأصل فعّل «إعادة إلى الافتراضي» ثم احفظ.
5. أضف روابط التواصل بصيغة HTTPS. لا تُعرض حسابات وهمية إذا كانت القيم فارغة.
6. ترتيب الأقسام قائمة أسماء مفصولة بفاصلة إنجليزية: `services,about,benefits,process,faq,contact`. غيّر الترتيب أو احذف قسمًا لإخفائه. إضافة نوع قسم جديد تحتاج مكونًا في `brand.js`، ثم إضافته لقائمة السماح في `brand.py`؛ ليست أداة بناء صفحات مفتوحة.
7. الحفظ عبر API مع جلسة وصلاحية provider وCSRF، في سجل `content.brand`. لا يستعمل LocalStorage لتخصيص الهوية العامة.
8. `GET /api/brand.css` يصدر متغيرات CSS من بيانات متحقق منها ويحملها كل مسار دون cache. لا يحتاج الحفظ إلى إعادة build.

### الأمان

حصر الألوان في hex، الخطوط والخيارات بقوائم سماح، حدود رقمية، الروابط HTTPS، PNG بهيدر وأبعاد محدودة. SVG بقائمة عناصر مع رفض scripts وevents وhref وstyles وDOCTYPE. الصور تُعرض في img لا تُحقن كـHTML. سياسة CSP الأصلية باقية؛ لا إضافة unsafe-inline أو مصادر خارجية. حد JSON الموسع لمسار الهوية فقط؛ بقية API تبقى بحدها السابق. حقل الهوية لا يغيّر بيانات الشركات.

## 5. الملفات

- `wasla/brand.py`: القيم الافتراضية والتحقق وإخراج CSS.
- `wasla/static/brand.css`: تصميم ومكونات وresponsive وmotion.
- `wasla/static/brand.js`: تكوين الصفحة ومحرر الإدارة.
- `wasla/static/brand/logo.png`: شعار المستخدم الأصلي دون تعديل ملفه.
- `wasla/static/fonts/`: Tajawal وManrope ورخصهما.
- `wasla/main.py`: المسارات `brand.css` و`admin/brand` وبيانات الهوية في catalog.
- `tests/test_brand.py`: حفظ، صلاحيات، CSRF، إدخال غير آمن، رفع وإعادة شعار.

## 6. الحدود الواضحة

الواجهة العامة عربية. يوجد فصل خط لاتيني وCSS يدعم اتجاه LTR، لكن ليس هناك ترجمة إنجليزية كاملة أو زر لغة يوحي بوجودها. تقنية Vanilla JS القائمة محفوظة لتجنب إعادة كتابة واجهة V1 ووظائفها؛ المكونات دوال مستقلة ولا تتطلب React لتنفيذ هذا النطاق. تغيير عناوين الخدمات والنصوص التسويقية التفصيلية يتم في المصدر، بينما «عن وصلة» وبيانات الاتصال والهوية قابلة للتحرير من الإدارة. أيقونة التبويب رمز SVG مبسط مستقل بألوان العلامة وليست تحويلًا متجهيًا مطابقًا للصورة.
